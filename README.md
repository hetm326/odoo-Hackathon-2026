
🌍 GlobeTrotter

GlobeTrotter is a smart travel planning web application developed for the Odoo Hackathon 2026.

It helps users easily plan trips, manage destinations, activities, budgets, and share their travel plans. ✈️🗺️

✨ Features:-
🔐 Login & Signup
🗺️ Create & Manage Trips
📍 Add Multiple Destinations
🎯 Add Activities
📅 Day-wise Itinerary
💰 Budget & Expense Management
🔗 Share Trips
👤 User Profile

🛠️ Technologies

🎨 Frontend:-
⚛️ React.js
🎨 Tailwind CSS
🔗 Axios

☕ Backend:-

☕ Java
🌱 Spring Boot
🔒 Spring Security
🔑 JWT Authentication

🗄️ Database:-
🐬 MySQL


🚀 How to Run
Frontend:-
npm install
npm run dev

🌐 Frontend:
http://localhost:3000

☕ Backend:-
Make sure MySQL is running, then start the Spring Boot backend

mvn spring-boot:run

🌐 Backend:
http://localhost:8080

🔗 Frontend & Backend Connection:-
👤 User
   ↓
⚛️ React Frontend
   ↓
🔗 Axios
   ↓
☕ Spring Boot REST API
   ↓
🐬 MySQL Database
